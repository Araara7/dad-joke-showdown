Entry for the [make.fun bounty "Dad Joke Showdown"](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5).

`main.py` writes one original dad joke to `/output/entry.txt` — I told my suitcase there would be no vacation this year. Now it's dealing with emotional baggage. Setup, then the pun lands on the last two words.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8, 97 characters).
The program is deterministic: running it twice writes exactly the same bytes.
It needs no network access and no dependencies beyond Python 3 stdlib.
